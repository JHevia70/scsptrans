TUTORIAL: Cómo identificar y eliminar procesos de fondo que penalizan el rendimiento en juegos
================================================================================================
Objetivo: encontrar procesos como audiodg.exe que consumen CPU innecesariamente y degradan los FPS.


1. IDENTIFICAR LOS PROCESOS QUE MÁS CONSUMEN CPU
--------------------------------------------------
Abre PowerShell y ejecuta:

    Get-Process | Sort-Object CPU -Descending | Select-Object -First 40 Name, CPU, @{N='RAM_MB';E={[math]::Round($_.WorkingSet/1MB,1)}} | Format-Table -AutoSize

Esto muestra los 40 procesos ordenados de mayor a menor consumo de CPU.
Fíjate en los que están por encima de 50-80 de CPU acumulado y que no sean el juego principal.


2. CASO REAL: audiodg.exe (Windows Audio Device Graph Isolation)
-----------------------------------------------------------------
Este proceso gestiona el audio de Windows. Con ciertos drivers (especialmente Realtek),
puede llegar a consumir 80-100 de CPU acumulado y causar stuttering y caídas de FPS.

Para verificar si está corriendo y cuánto consume:

    Get-Process -Name audiodg | Select-Object Name, CPU, @{N='RAM_MB';E={[math]::Round($_.WorkingSet/1MB,1)}}


3. REDUCIR EL CONSUMO DE audiodg.exe
--------------------------------------
Antes de eliminarlo, prueba estas opciones menos agresivas:

a) Desactivar mejoras de sonido:
   - Panel de Control > Sonido > clic derecho en tu dispositivo de audio > Propiedades
   - Pestaña "Mejoras" > marcar "Deshabilitar todas las mejoras"
   - Pestaña "Opciones avanzadas" > desmarcar "Permitir que las aplicaciones tomen control exclusivo"

b) Cambiar la calidad de audio:
   - En la misma ventana, pestaña "Opciones avanzadas"
   - Bajar la calidad a 16 bits, 44100 Hz (calidad de CD)

c) Desactivar el audio espacial:
   - Clic derecho en el icono de volumen (barra de tareas) > Configuración de sonido
   - Asegurarse de que el audio espacial esté en "Desactivado"


4. DESHABILITAR EL SERVICIO DE AUDIO DE REALTEK (RtkAudioUniversalService)
---------------------------------------------------------------------------
Si el problema persiste, puedes deshabilitar el servicio universal de Realtek:

    # Ver estado actual
    Get-Service -Name RtkAudioUniversalService

    # Detenerlo temporalmente (hasta el próximo reinicio)
    Stop-Service -Name RtkAudioUniversalService

    # Deshabilitarlo permanentemente (no arranca con Windows)
    Set-Service -Name RtkAudioUniversalService -StartupType Disabled

Para reactivarlo si hay problemas de audio:

    Set-Service -Name RtkAudioUniversalService -StartupType Automatic
    Start-Service -Name RtkAudioUniversalService


5. BUSCAR TAREAS PROGRAMADAS DE REALTEK QUE SE RELANCEN SOLAS
--------------------------------------------------------------
Algunos procesos tienen un "watchdog" que los relanza. Para verificarlo:

    Get-ScheduledTask | Where-Object { $_.TaskName -match "realtek|audio|rtk" } | Select-Object TaskName, State

Si encuentras alguna, deshabilitarla:

    Disable-ScheduledTask -TaskName "NOMBRE_DE_LA_TAREA"


6. OTROS PROCESOS DE FONDO COMUNES QUE PENALIZAN EL RENDIMIENTO
----------------------------------------------------------------
Estos son procesos conocidos que conviene cerrar antes de jugar:

    Proceso                  | CPU aprox | RAM aprox | Acción
    -------------------------|-----------|-----------|---------------------------
    audiodg.exe              | ~83       | ~29 MB    | Ver pasos 3 y 4
    Discord (x3 procesos)    | ~90       | ~980 MB   | Cerrar o usar versión web
    OneDrive + Sync.Service  | ~72       | ~330 MB   | Pausar sincronización
    lghub_agent (Logitech)   | ~77       | ~168 MB   | Cerrar si no se usa
    msedge + webview2 (x4)   | ~55       | ~507 MB   | Cerrar Edge antes de jugar
    WhatsApp                 | ~11       | ~202 MB   | Cerrar antes de jugar
    Creative Cloud (Adobe)   | ~46       | ~345 MB   | Deshabilitar del inicio


7. DESHABILITAR PROGRAMAS DEL INICIO DE WINDOWS
------------------------------------------------
Para que los programas no arranquen con Windows:

    # Ver todos los programas de inicio
    Get-CimInstance Win32_StartupCommand | Select-Object Name, Command, Location | Format-Table -AutoSize

    # O usar el Administrador de tareas:
    # Ctrl+Shift+Esc > pestaña "Inicio" > clic derecho > Deshabilitar


8. COMANDO RÁPIDO ANTES DE JUGAR
---------------------------------
Puedes ejecutar esto en PowerShell antes de iniciar Star Citizen para ver el estado actual:

    Get-Process | Sort-Object CPU -Descending | Select-Object -First 20 Name, CPU, @{N='RAM_MB';E={[math]::Round($_.WorkingSet/1MB,1)}} | Format-Table -AutoSize
